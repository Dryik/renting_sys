# Small Desktop UX Skill

This app is for non-technical staff in small rental shops.

Follow these rules:
- Prefer one clear primary action per screen.
- Use simple labels, not technical terms.
- Use large readable tables.
- Put search at the top of list screens.
- Avoid nested menus.
- Avoid hidden actions.
- Use confirmation dialogs for destructive actions.
- Use status badges with clear wording.
- Empty states must explain what to do next.
- Forms should be short and grouped logically.
- Do not add advanced filters unless explicitly requested.

For list screens:
- Add button at top right.
- Search at top left.
- Table in the center.
- Actions on the right side of each row.

For forms:
- Required fields should be obvious.
- Validation messages should be plain language.
- Save and Cancel buttons should be visible at the bottom.
