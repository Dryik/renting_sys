# PDF and Printing Skill

Keep PDF and printing simple.

The first version should produce plain, readable A4 documents.

Rental contract PDF should include:
- Shop name
- Shop phone/address if available
- Contract number
- Customer details
- Vehicle details
- Start date and time
- Expected return date and time
- Daily price
- Deposit
- Mileage out
- Fuel out
- Notes
- Terms/footer text
- Customer signature field
- Shop signature field

Payment receipt PDF should include:
- Shop name
- Receipt number or payment ID
- Contract number
- Customer name
- Vehicle plate number
- Payment date
- Payment type
- Payment method
- Amount
- Notes if available

Rules:
- Do not spend time on perfect design first.
- Make it readable and printable first.
- Avoid complex PDF layouts.
- Use clear spacing.
- Make A4 output the default.
- Do not add bilingual PDF support unless explicitly requested.
