# Rental Desk v0.3.9 data cleanup

## Recommended: one portable file

Use `ARAK-v0.3.9-Data-Cleanup-1.0.0.exe` on the Rental Desk computer. It is a
portable Windows x64 tool: it does not need installation, Node.js, npm, or a
terminal. Windows 11 x64 with 8 GB RAM is supported.

1. Close Rental Desk completely.
2. Copy the cleanup `.exe` to the target computer and double-click it.
3. Review the displayed customer and vehicle counts.
4. Tick the confirmation box and choose **Back up and clean**.
5. Save the automatically created safety-backup ZIP somewhere easy to find,
   preferably the Desktop or a USB drive.
6. Wait for the success message, then reopen Rental Desk and verify the data.

The helper refuses to run if Rental Desk is open or if the database is not the
exact released v0.3.9/schema-11 layout. It verifies the full backup before
changing data, checks the cleaned database afterward, and automatically restores
the backup if cleanup or verification fails. Administrator access is not needed.

## What stays

- customers and their uploaded documents/photos
- vehicles and their uploaded documents/photos
- vehicle details, prices, mileage, and non-rented status
- login users, roles, and permissions
- shop settings and required money-location definitions

Vehicles whose current status is `rented` become `available`, because their
rental is removed. Existing `maintenance` and `inactive` statuses are retained.

## What is cleared

- rentals, contracts, payments, receipts, collateral, and rental accessories
- accounting adjustments, expenses, cash movements, and daily closings
- maintenance records/reminders and vehicle mileage event history
- employee loans and repayments
- vehicle-sale history
- accessories
- operational/audit events and document-number sequences
- attachment records not belonging to a customer or vehicle, plus the files
  referenced only by those removed records

## After cleanup

Verify:

- the customer count and customer documents
- the vehicle count, documents, mileage, prices, and statuses
- Rentals, Payments, Accounting, Maintenance, and Reports are empty
- formerly rented vehicles are available

Keep the safety-backup ZIP. It contains the original database and uploads from
before cleanup.

## Advanced development-computer method

The backup-conversion command remains available for testing or support work. It
never edits the installed database or overwrites the source backup.

Preview a v0.3.9 backup:

```powershell
npm run cleanup:v0.3.9 -- --input "D:\Backups\rental_backup.zip" --dry-run
```

Create a separate cleaned backup:

```powershell
npm run cleanup:v0.3.9 -- --input "D:\Backups\rental_backup.zip" --output "D:\Backups\rental_backup_customers_vehicles_only.zip" --execute --confirm CLEAR-V0.3.9-TRANSACTIONS
```
