# Version 1 Scope

This app is for small rental shops with one Windows desktop or laptop.

## Version 1 Includes

### Vehicles

- Add vehicle
- Edit vehicle
- Search vehicles
- Vehicle status
- Daily price
- Deposit amount
- Plate number
- Type: car or motorcycle
- Insurance expiry
- Registration expiry
- Notes

### Customers

- Add customer
- Edit customer
- Search customers
- Name
- Phone
- National ID / Passport
- Driver license number
- Address
- Notes

### Rentals

- Create rental contract
- Select customer
- Select available vehicle
- Start date/time
- Expected return date/time
- Daily price
- Deposit
- Mileage out
- Fuel level out
- Notes
- Activate rental
- Print or export contract PDF

### Returns

Returns should be handled inside the active rental workflow.

- Return vehicle
- Actual return date/time
- Mileage in
- Fuel level in
- Damage notes
- Extra charges
- Discount
- Final amount
- Deposit refund
- Mark vehicle available or maintenance

### Payments

- Record payment
- Payment type
- Payment method
- Amount
- Date
- Related rental

### Dashboard

- Available vehicles
- Rented vehicles
- Overdue rentals
- Expected returns today
- Income today

### Reports

- Active rentals
- Returned rentals
- Overdue rentals
- Daily payments
- Vehicle income
- Customer rental history

### Settings

- Shop name
- Phone
- Address
- Default currency
- Default late fee
- Contract footer text

### Backup / Restore

- Manual backup
- Restore from backup
- Backup includes database and uploaded files

## Version 1 Excludes

- Online booking
- Cloud database
- Multi-branch
- GPS tracking
- Automatic SMS/WhatsApp
- Advanced accounting
- VAT/tax engine
- Employee payroll
- Complex role permissions
- Mobile app
- SaaS login
- AI features

## Product Rule

If a feature does not help the shop answer “who has which vehicle, when is it due, and how much money is owed?”, postpone it.
